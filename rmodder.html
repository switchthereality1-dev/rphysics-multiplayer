Сценарий мода

Слева выбери блоки — они появятся здесь.
Блоки собираются сверху вниз, как в Scratch.

      

      

        
      

      

        

          
          
          
          
        

        
Полная свобода: пиши ЛЮБОЙ JSON мода rmod/2, включая поля, которых нет в блоках.
          Пока режим включён, «Скачать .rmod» берёт именно этот JSON. Свойства движка доступны из скрипта через api.E / window.RDBG.

        
        
режим выключен — работает сборка из блоков

      

      

        0. Не хочешь блоки? Вкладка 🆓 Свой JSON — пиши любой JSON мода руками, движок поддерживает всё. В скрипте доступен весь движок: api.E = window.RDBG.

        1. Собери мод блоками слева.

        2. Нажми «Скачать .rmod» — получится файл мода.

        3. Открой игру rphysics/index.html → меню 🧩 Моды (RModder) → 📂 Файл .rmod.

        4. Мод появится в списке, его можно включать/выключать.


        Через ИИ: нажми «Промпт для ИИ», скопируй текст и отдай любой нейросети (Arena, DeepSeek, что угодно).
        Она вернёт JSON — вставь его в меню модов игры в поле «Вставить мод из текста». Или загрузи этот JSON
        сюда кнопкой «Открыть .rmod», чтобы доработать блоками.


        Что умеет мод: скины предметов (цвета и размер), свои предметы с уроном, тюнинг боя и бега,
        новые цвета NPC, предметы на картах, свои существа (летающие коты-камикадзе, бомбардировщики,
        любые твари из кубиков), спавнеры по таймеру и свой JS-скрипт с хуком onFrame.


        
        
Так нож выглядит с выбранными цветами.
